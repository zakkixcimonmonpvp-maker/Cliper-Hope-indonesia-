Roadmap belajar

Pelajari berurutan dan centang tahap yang sudah kamu pahami.

Progres belajarmu
0% selesai
1💻

IT FUNDAMENTAL

Kenali cara kerja komputer dan sistem operasi.

  • Hardware dan software
  • Dasar Windows dan Linux
  • CMD dan PowerShell dasar
  • File system dan virtual machine
  • Troubleshooting
2🌐

NETWORKING

Pahami bagaimana perangkat saling terhubung.

  • OSI dan TCP/IP
  • IP address, subnet, gateway
  • DNS, DHCP, HTTP/HTTPS
  • Router, firewall, VPN, Wi-Fi
  • VLAN dan konsep port
3🐧

LINUX

Belajar terminal dan mengelola sistem Linux.

  • Perintah dasar Linux
  • Permission dan user
  • Process dan service
  • SSH dan koneksi aman
  • Bash scripting dasar
4🛡️

SECURITY FUNDAMENTAL

Prinsip dasar untuk menjaga data dan perangkat.

  • CIA Triad
  • Autentikasi dan MFA
  • Enkripsi dan hashing
  • Access control
  • Vulnerability, threat, risk
5🔎

THREAT AWARENESS

Kenali ancaman siber agar mampu mencegahnya.

  • Phishing dan social engineering
  • Malware dan ransomware
  • Risiko kata sandi lemah
  • Incident response dasar
  • Backup dan pemulihan
Fokus pada pengenalan ancaman dan pertahanan.
6🧩

WEB SECURITY

Kenali komponen website dan cara merancang aplikasi aman.

  • HTML, CSS, JavaScript
  • HTTP request dan response
  • Cookie dan session
  • Validasi input dan output
  • Konsep risiko XSS dan SQL injection
Latihan hanya di website sendiri atau lab yang mengizinkan.
7🧰

SECURITY TOOLS

Kenali alat untuk mengamati jaringan dan kondisi keamanan.

  • Wireshark untuk memahami trafik
  • Log dan system monitoring
  • Vulnerability assessment berizin
  • Patch management
  • Audit konfigurasi
Gunakan hanya pada sistem yang kamu miliki atau diizinkan.
8🔵

BLUE TEAM

Fokus pada pemantauan, deteksi, dan respons ancaman.

  • Log analysis
  • Windows Event Log
  • Konsep SIEM dan EDR
  • IDS/IPS
  • Threat intelligence
  • Incident response
9⚙️

AUTOMATION

Otomatiskan tugas rutin agar pekerjaan lebih konsisten.

  • Python dasar dan pemrosesan data
  • Bash atau PowerShell
  • API dan JSON
  • Otomatisasi laporan
  • Penjadwalan tugas
Materi tidak ditemukan. Coba kata kunci lain.

Pilih spesialisasi

Setelah memahami dasar, pilih bidang yang ingin didalami.

🔵 Blue Team

Monitoring, deteksi, dan incident response.

🔴 Red Team

Simulasi keamanan yang sah dan terotorisasi.

🟣 Purple Team

Kolaborasi pengujian dan pertahanan.

☁️ Cloud Security

Keamanan layanan cloud dan identitas.

📋 GRC

Governance, risk, compliance, kebijakan.

Rencana dan kebiasaan belajar

Contoh jadwal yang bisa kamu sesuaikan.

🗓️ Rencana 8 minggu

  • Minggu 1–2: IT Fundamental dan Networking.
  • Minggu 3: Linux dan terminal dasar.
  • Minggu 4: Security Fundamental.
  • Minggu 5–6: Threat Awareness dan Web Security.
  • Minggu 7–8: Security Tools, Blue Team, Automation.

✅ Kebiasaan aman

  • Catat istilah yang belum dipahami.
  • Gunakan virtual machine atau lab pribadi.
  • Aktifkan MFA dan kata sandi unik.
  • Perbarui perangkat dan buat backup.
  • Minta izin sebelum menguji sistem.
